## Preserve throughout the batch

Check and Start must resolve the same request. Save must preserve supported intent without a device. Applying a visual resource must not mutate engineering properties. Missing scene bindings, unsupported effects, calibration blockers and ambiguous light-energy ownership must produce explicit outcomes, not silent approximations. Cancellation, final-only export, source hashes and allocation accounting remain active.

The improved SELENE native source still needs its separate source-lock admission. No obsolete body ordinals or older rover file are substituted for it here. Original authoring-only height maps remain distinct from runtime displacement.
